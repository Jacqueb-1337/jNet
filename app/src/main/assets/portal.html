    Step 2

    Import the jNet connection

    Do not create any proxy groups or nodes by hand. This profile already contains them.

    Your host has enabled a SOCKS5 password. Enter the password provided by the host to create a private, 10-minute import link. Use this only on a trusted Wi-Fi network: the captive page uses HTTP.
    If the captive sign-in window blocks opening FlClash, open this page in your full browser. If the import button still fails, use Copy profile URL and import it from FlClash's Profiles screen.
    Step 3

    Enable full-app networking

    1. In FlClash, apply the imported jNet profile. Leave routing mode on Rule, not Direct.
    2. On Android, open Dashboard → Edit, add the VPN control if missing, then exit editing.
    3. Turn on VPN and approve Android's VPN request. On desktop, enable TUN and authorize it when prompted.
    4. Open a website and verify the host phone's jNet traffic counters increase.
